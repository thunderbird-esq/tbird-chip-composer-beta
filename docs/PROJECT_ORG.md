# Project Organization

This repository is structured so all client code lives in `src/` and documentation in `docs/`. Tests reside in `tests/` and are run with Node or in-browser via `test-runner.html`.

* `src/` - ES modules for audio engine, UI components and utilities
* `styles/` - CSS including `system.css` for the retro look
* `build.sh` - simple build script copying assets to `dist/`

Contributions follow the standard GitHub fork-and-PR workflow.
